## 📁 Структура файлов проекта

```
src/
├── 📄 main.cpp                    ← ГЛАВНЫЙ (только setup + loop, 90 строк!)
│
├─ КОНФИГУРАЦИЯ (редко меняется)
├── 📄 config.h                    ← Все константы
├── 📄 types.h                     ← Типы данных и перечисления
│
├─ СОСТОЯНИЕ (часто используется)
├── 📄 app_state.h                 ← Объявления глобальных переменных
├── 📄 app_state.cpp               ← Определения переменных
│
├─ АППАРАТУРА И ВВОД
├── 📄 matrix_keyboard.h
├── 📄 matrix_keyboard.cpp         ← Матричная клавиатура 74HC595 + 74HC165
├── 📄 keyboard_map.h              ← Маппинг встроенной клавиатуры
│
├─ MIDI И ЗВУК
├── 📄 midi_helpers.h
├── 📄 midi_helpers.cpp            ← Вспомогательные функции MIDI
├── 📄 ble_midi_handler.h
├── 📄 ble_midi_handler.cpp        ← BLE MIDI управление
│
├─ ИНТЕРФЕЙС И ЛОГИКА
├── 📄 display.h
├── 📄 display.cpp                 ← Рисование UI (самый большой, 230 строк)
├── 📄 menu_logic.h
├── 📄 menu_logic.cpp              ← Логика меню (I/K/J/L/Enter)
├── 📄 play_mode.h
├── 📄 play_mode.cpp               ← Логика режима игры
│
└── platformio.ini                 ← Конфиг PlatformIO
```

## ❓ Частые вопросы

**Q: Это нарушит совместимость?**
A: Нет! Функциональность идентична. Только переорганизован код.

**Q: Нужно ли пересчитывать что-то в матрице?**
A: Нет, все параметры матрицы остались те же в config.h.

**Q: Могу ли я вернуться к старому коду?**
A: Конечно, у тебя есть исходный файл. Но не рекомендуем - новая версия намного лучше!

**Q: Сколько времени займёт переход?**
A: 5 минут на копирование + 1 минута на компиляцию. Итого 6 минут.

**Q: Что если у меня кастомные изменения в main.cpp?**
A: Переноси их в соответствующие модули согласно [README_STRUCTURE.md](README_STRUCTURE.md).
